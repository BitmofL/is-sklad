# ИС «Склад» — информационная система складского учёта

> Курсовой проект: десктопное приложение **C# / WinForms** для автоматизации складского
> учёта, с базой данных **MS SQL Server** (ADO.NET) и полным набором проектной
> документации (UML, DFD, ТЗ). Автор: Бугаев Евгений Валерьевич.

## Возможности
- Справочники: **товары**, **категории**, **поставщики**, **склады**, **клиенты**.
- Операции движения товаров: **приёмка**, **отгрузка**, **перемещение** между складами.
- **Инвентаризация**.
- Отчёты: **складские остатки**, **движение товаров**.
- Настройки и «О программе».

## Технологии
| Слой | Технология |
|---|---|
| Язык | C# (.NET Framework 4.8) |
| UI | Windows Forms |
| Доступ к данным | ADO.NET (`System.Data.SqlClient`), типизированные DataSet (.xsd) |
| БД | MS SQL Server |

## Структура
```
ИС Склад.sln
MainForm.*                 # главное меню (MDI)
ProductForm/AddProductForm # товары
CustomersForm, SuppliersForm, WarehousesForm
ReceiveGoodsForm, ShipGoodsForm, MoveGoodsForm
InventoryForm
StockBalanceReportForm, GoodsMovementReportForm
AboutForm, SettingsForm
kurse_26ip212DataSet.xsd   # типизированный DataSet
```

## Схема БД
Таблицы: `КатегорииТоваров`, `Товары`, `Поставщики`, `Склады`, `СкладскиеОстатки`,
`Клиенты`, `Отгрузки`. SQL-скрипт — `docs/код sql.txt`.

## Проектная документация (`docs/`)
- **ТЗ** (`TZ.docx`) и **пояснительная записка** (`ПП_Бугаев.docx`).
- UML: вариантов использования, деятельности, кооперации, пакетов, последовательности (`.vsdx`).
- Функциональные модели: контекстная диаграмма и DFD (`.rsf`).

## Запуск
1. Выполнить `docs/код sql.txt` в MS SQL Server (создаёт БД `kurse_26ip212`).
2. Строка подключения задаётся в `App.config`/коде (по умолчанию LocalDB).
3. Открыть `ИС Склад.sln` в Visual Studio и запустить.
